# Skill research for November 24, 2026

The first skill targets false confidence from friendly sample copy. Models can reproduce a screenshot and verify a narrow viewport while keeping the same short strings at every width. That leaves the content variable untested. Flexbox's automatic minimum size can preserve an unbreakable item at a width larger than its component can accommodate. The W3C reflow guidance gives a useful 320 CSS px reference point where applicable. The project's demo shows the failure and the regression check. It is evidence for the failure mode rather than a benchmark of model performance. [CSS Flexbox specification](https://www.w3.org/TR/css-flexbox-1/#min-size-auto) · [W3C reflow guidance](https://www.w3.org/WAI/WCAG22/Understanding/reflow.html)
